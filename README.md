# AITECH CI — Médias marketing

Dépôt public des visuels et vidéos publiés sur les réseaux sociaux d'AITECH Côte d'Ivoire.

- `tools/aitech_studio.py` : moteur de création (images PNG 4 formats, vidéos MP4) aux couleurs AITECH.
- `medias/AAAA-MM-JJ/` : médias prêts à publier, servis via
  `https://raw.githubusercontent.com/NILGITH/aitech-ci-medias/main/medias/AAAA-MM-JJ/<fichier>`
  et programmés par Metricool.

AITECH CI : Connecter, Innover, Transformer.
